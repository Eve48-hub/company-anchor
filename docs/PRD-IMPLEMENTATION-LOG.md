## 고도화 #1 — 재무 탐색·관심기업·SEO 안전장치

### 구현

- `/company/{slug}/financials` 정적 재무 상세 페이지
- 전체·손익계산서·재무상태표 필터
- 원·백만원·억원 단위 변환
- 3개년 매출 차트와 계정과목 × 연도 테이블
- 브라우저 `localStorage` 기반 관심기업 저장·해제·재방문 유지
- 샘플 기업·검색 페이지 `noindex, nofollow`
- canonical, `sitemap.xml`
- GitHub Pages 프로젝트 사이트에서는 `/company-anchor/robots.txt`가 원본 도메인의 robots 정책으로 효력이 없으므로 생성하지 않고 페이지별 `noindex`를 사용
- 실제 API 미연동 기능은 비활성 또는 `준비 중`으로 표시
- 로컬 QA를 위한 Next.js `allowedDevOrigins`

### TDD 기록

1. 재무 기간 선택·단위 변환 실패 테스트 작성
2. 관심기업 저장·해제·중복 방지 실패 테스트 작성
3. 샘플 페이지 색인 차단·canonical 실패 테스트 작성
4. 최소 구현 후 전체 테스트 통과

### 검증

- Vitest: 5개 파일, 22개 테스트 통과
- TypeScript strict 검사 통과
- Next.js 정적 빌드 통과
- 11개 정적 페이지 생성
- 재무 필터를 `재무상태표`로 변경했을 때 자산·부채·자본만 노출 확인
- 관심기업 저장 후 새로고침해도 `저장됨` 유지 확인
- 기업·재무·검색 샘플 페이지 `noindex` 확인
- 재무 canonical과 sitemap URL 확인
