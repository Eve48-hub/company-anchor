# 한국 무료 기업·재무정보 MVP — API/데이터 타당성 매트릭스

> 조사 기준: 2026-08. 공식·권리승인 소스를 우선했다. API 키는 문서에 기록하지 않으며 서버 비밀 저장소에서만 사용한다.

## 1. 결론

- **핵심 MVP는 조건부 GO**: `금융위원회 기업기본정보 → OpenDART → 국세청 사업자상태`의 3계층으로 구성한다. 다만 서비스 범위는 **“대한민국 모든 사업자”가 아니라, 법인 식별이 되고 DART/금융위 데이터에 잡히는 기업**으로 명확히 제한해야 한다.
- **OpenDART는 재무·공시의 기준 소스**다. 공시대상 회사의 기업개황, 공시, XBRL 주요계정·전체 재무제표·재무지표를 제공하며 일반 요청 제한은 20,000건 수준이다.[1][2]
- **국세청 API는 검색/기업명부 API가 아니다.** 이미 알고 있는 사업자등록번호의 휴·폐업/과세상태 확인 또는 사용자가 입력한 등록정보의 진위확인에만 쓴다. 1회 100건, 1일 100만건이고 30분 주기로 동기화된다.[4]
- **무료 뉴스 자동연동은 NO-GO**: BIGKinds는 무료 전환 정책에 따라 기존 OPEN API의 신규 기능 신청을 중단했고, 필요한 데이터는 뉴스스토어 유료 구매로 안내한다.[6][7]
- **KIPRIS Plus·NTIS는 2차 옵션**: 핵심 기업/재무 기능의 유효성을 먼저 검증한 뒤 특허·R&D 시그널이 전환율을 실제로 높일 때만 붙인다.

## 3. 개발 전 의사결정 단계

### Stage 0 — 권리·계정 승인 (코딩 금지, 2~5영업일 목표)

1. OpenDART, data.go.kr 2종, NTIS(선택), KIPRIS Plus(선택)에 회사 명의 계정/활용 목적을 등록한다.
2. 키·승인메일·현재 약관을 비밀 저장소/법무 폴더에 보관하고, PRD에는 키를 넣지 않는다.
3. 각 원천에 대해 `상업적 웹서비스`, `응답 캐시`, `가공지표`, `원문 재배포`, `출처표시` 가능 여부를 체크한다.
4. **통과 기준**: P0 3종 승인, 비용 0원, 운영 트래픽 증량 절차 확인, 금지되는 재배포 항목 없음. 하나라도 불명확하면 API 코딩 대신 제공기관 서면문의.

### Stage 1 — 무코드/단발성 API 스파이크

- Postman/curl로 층화표본 200개를 조회하고 원응답·상태코드·응답시간·필드 결측을 기록한다.
- 목표 지표:
  - canonical 회사 매칭 정밀도 **≥98%**, 오탐 **≤1%**, ambiguous **≤5%**
  - DART 대상 기업의 최근 재무 응답률 **≥90%**
  - 재무 핵심계정(매출, 영업이익, 당기순이익, 자산, 부채, 자본) 매핑 성공률 **≥95%**
  - 국세청 알려진 사업자번호 정상응답률 **≥99.5%**
  - 소스별 p95 응답시간 **≤2초** 또는 캐시 후 사용자 p95 **≤500ms**
  - 예상 일일 호출량이 승인 한도의 **50% 이하**
- **Kill gate**: 일반 비상장/소상공인까지 동일한 자동 프로필을 약속해야 하는데 법인번호/사업자번호 확보율이 70% 미만이면 제품 포지셔닝을 “공시·법인 기업정보”로 바꾸기 전까지 개발 중단.

### Stage 2 — P0 MVP 구현

1. `source_entity`(원천 식별자)와 `canonical_company`를 분리한다.
2. 이름만 같은 경우 자동 병합하지 않는다. 법인번호/사업자번호 일치만 확정 병합하고, 나머지는 후보 UI를 제공한다.
3. OpenDART corpCode 전체파일을 배치 적재하고, 상세/재무는 on-demand+캐시한다.
4. 국세청 상태는 사용자 조회 시 또는 최근성이 필요한 경우에만 호출한다.
5. 모든 숫자에 `source`, `as_of`, `report_code`, `fs_div`, `currency/unit`, `retrieved_at`를 저장·표시한다.
6. 연결(CFS)과 별도(OFS) 재무를 섞지 않으며, 연간/분기 값을 별도 시계열로 유지한다.

### Stage 3 — 옵션 실험

- 뉴스: 무료 기능에서는 제외. 유료 뉴스 계약과 전재/노출권이 확보된 뒤 별도 Go/No-Go.
- KIPRIS/NTIS: 핵심 프로필 사용자의 20% 이상이 “특허/R&D”를 클릭하거나, 해당 신호가 리드 전환을 10% 이상 개선할 때만 2주 PoC.

## 4. 권장 MVP 화면 범위

- 회사 검색: 기업명 후보 + 법인/사업자/DART/종목 식별자
- 기업개요: 대표자, 설립일, 업종, 주소, 홈페이지, 상장구분, 상태(번호 보유 시)
- 재무: 최근 3~5개년 핵심계정, 연결/별도 표시, 원 공시 링크
- 공시: 최근 공시 목록과 DART 원문 링크
- 명시적 비지원: 모든 개인사업자 이름검색, 신용등급/추정매출, 언론기사 본문, 실시간 주가

## 5. 최종 Go/No-Go

- **GO**: “공시기업 및 식별 가능한 한국 법인”을 대상으로 무료 기업개요·공시·재무·사업상태를 제공하는 MVP.
- **CONDITIONAL**: 일반 비상장 법인 검색은 금융위 API의 실제 표본 커버리지 통과 후 포함.
- **NO-GO**: 공식 무료 소스만으로 모든 사업자/개인사업자의 기업명 검색, 포괄 재무, 무료 뉴스 본문을 제공한다는 약속.
- **DEFER**: KIPRIS Plus와 NTIS는 핵심 제품지표가 나온 뒤 확장.
